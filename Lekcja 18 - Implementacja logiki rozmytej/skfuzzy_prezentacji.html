3. Moduł membership

Funkcje przynależności — najważniejsze kształty

trimf

funkcja trójkątna
fuzz.trimf(x, [a, b, c])

Jeden najlepszy punkt. Przynależność rośnie do 1, a potem maleje.

Przykład: „średnie HP”, „umiarkowana temperatura”.

trapmf

funkcja trapezowa
fuzz.trapmf(x, [a, b, c, d])

Cały idealny przedział. Przez pewien zakres wartość μ = 1.

Przykład: „komfortowa temperatura”, „bezpieczna odległość”.

gaussmf

funkcja Gaussa
fuzz.gaussmf(x, mean, sigma)

Gładki dzwon. Im dalej od środka, tym mniejsza przynależność.

Przykład: płynne przejścia bez ostrych załamań.

4. Moduł control

Moduł control — z czego składa się system?

Antecedent

Zmienna wejściowa, np. HP gracza albo odległość.

ctrl.Antecedent(universe, label)
universe — zakres wartości
label — nazwa zmiennej

Rule

Reguła typu IF–THEN: warunek → decyzja.

ctrl.Rule(antecedent, consequent)
antecedent — warunek IF
consequent — wynik THEN
↓

ControlSystem

łączy wszystkie reguły w jeden system

ctrl.ControlSystem(rules)
rules — lista reguł
↓

Consequent

Zmienna wyjściowa, np. poziom ataku.

ctrl.Consequent(universe, label)
universe — zakres wartości
label — nazwa zmiennej

Simulation

Wprowadzamy dane i uruchamiamy obliczenia.

ctrl.ControlSystemSimulation(system) sim.compute()
system — gotowy ControlSystem
compute() — liczy wynik, bez argumentów
4. Moduł control

System rozmyty w kodzie — szkielet

1

Zmienne

hp = ctrl.Antecedent(np.arange(0,101,1), 'hp') distance = ctrl.Antecedent(np.arange(0,51,1), 'distance') attack = ctrl.Consequent(np.arange(0,101,1), 'attack')
2

Funkcje przynależności

hp['low'] = fuzz.trimf(hp.universe, [0,0,40]) distance['close'] = fuzz.trimf(distance.universe, [0,0,15]) attack['strong'] = fuzz.trimf(attack.universe, [80,100,100])
3

Reguły

r1 = ctrl.Rule(hp['low'], attack['strong']) r2 = ctrl.Rule(hp['medium'] & distance['close'], attack['careful'])
4

Symulacja

system = ctrl.ControlSystem([r1, r2]) sim = ctrl.ControlSystemSimulation(system) sim.input['hp'] = 35 sim.input['distance'] = 12 sim.compute()

Najważniejsze: Antecedent = wejście, Consequent = wyjście, Rule = zasada, ControlSystem = całość.

5. Moduł defuzzify

fuzz.defuzzify — centroid

Po co centroid?

Po regułach wynik jest nadal wykresem rozmytym. Centroid zamienia go na jedną konkretną liczbę.

centroid = środek ciężkości pola
wynik = fuzz.defuzz(x, mfx, 'centroid')

Argumenty

x — zakres wartości wyjścia, np. 0–100
mfx — zagregowany zbiór rozmyty po regułach
'centroid' — metoda defuzyfikacji
6. Moduł fuzzymath

fuzz.fuzzymath — AND, OR, NOT

Te operacje mówią, jak łączyć stopnie przynależności.

AND

iloczyn

fuzz.fuzzy_and(x, A, y, B)
μ = min(A, B)

Warunek jest tak mocny, jak jego słabsza część.

OR

suma

fuzz.fuzzy_or(x, A, y, B)
μ = max(A, B)

Wystarczy, że mocno działa jeden z warunków.

NOT

dopełnienie

fuzz.fuzzy_not(A)
μ = 1 - A

Odwraca stopień przynależności.

x, y — zakresy wartości, A, B — tablice przynależności. W module control zapisujemy to krócej: &, |, ~.
